# Sheet 09 — solution files

Run every program from its own folder, for example `cd A2-temperature` and then
`python table.py`.

| Folder | Run | Shows |
|---|---|---|
| `A1-six-imports` | `python p1.py` … `python p5.py`, then `cd p6` and `python main.py` | the six results, two of them errors |
| `A2-temperature` | `python temperature.py`, then `python table.py` | the tests, then the table without them |
| `A3-dice` | `python dice.py` | the counts with seed 2026 |
| `A4-median` | `python check_median.py` | `0 434` |
| `B1-file-contents` | `python run_all.py` | the contents of `t.txt` after each program. Restores `t.txt` at the end |
| `B2-reader` | `python read_numbers.py` | the skipped line, the mean, and a missing file |
| `B3-report` | `python report.py` | the dictionary, then `courses.txt` |
| `B4-high-scores` | `python scores.py`, then `python classmate.py` | `90 75 75 60 40`, then only `12`. Delete `scores.txt` between the two |
| `extra` | `python wordcount.py` | the ten most common words of `my_text.txt` |
